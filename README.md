# 少邻国

少邻国是一款把网页外文直接改写成简体中文的 Chrome 扩展。它不在旁边另开翻译框，也不把译文盖成贴片；网页显示时，标题、正文、按钮和动态加载的评论会直接变成中文。

![少邻国封面](store-assets/cover-1400x560.png)

## 主要功能

- 自动识别网页原文语言，固定翻译为简体中文，不需要用户选择原文或目标语言。
- 自动识别英语、法语、西班牙语、日语、韩语、俄语、德语等网页原文，不需要用户选择原文语言。
- 优先使用 Chrome 设备端模型翻译成中文；对应语言对不可用或返回原文时，自动切换到少邻国本机语义翻译。
- 直接修改网页原有文字节点，不生成悬浮窗、截图或翻译贴片。
- 搜索结果摘要、卡片副标题等普通可见文字也会原位翻译，不再只识别标题和段落标签。
- GitHub 等网页的短菜单、导航项、辅助说明会使用易懂中文，不会再因产品词过短而原样残留。
- 只处理新增或进入视口的文字，并限制翻译队列与缓存，不在后台反复扫描整张网页。
- 同一浏览器会话内复用已完成的译文，刷新网页时不重复运行相同的语言检测和翻译。
- 网页端优先使用 Chrome 轻量翻译；仅在轻量翻译不可用或没有产生有效译文时，才按需调用本机语义翻译。
- 对 YouTube 使用独立的可见评论扫描，滚动到评论区后持续翻译新加载的评论，不扫描屏幕外的整页内容。
- 自动保留文件名、路径、网址、电子邮箱、代码标识，以及 GitHub 用户名、仓库名、分支名和文件路径。
- 可维护“不翻译词表”，默认保留 KFC、YouTube、Google、Apple、macOS 等名称。
- 弹窗使用紧凑的纯黑样式，明确显示固定翻译为简体中文。
- 网页自动翻译优先使用 Chrome 设备端轻量翻译能力，无法完成的少量内容再由少邻国本机语义翻译服务兜底。

## 使用

1. 安装并启用少邻国。
2. 打开普通网页。
3. 少邻国会自动识别外语，并在原文字位置直接变成简体中文。

扩展会从当前视口开始翻译，并在滚动时处理新出现的内容。文件名、网址和“不翻译词表”中的专有词不会被改写。

## 本地安装

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 选择“加载未打包的扩展程序”，然后选择本仓库目录。

## 数据处理

少邻国不会把网页内容发送到开发者服务器。翻译通过 Chrome 的设备端翻译能力完成；如果用户在本机运行少邻国语义翻译服务，扩展只会连接 `127.0.0.1:11436`。详细说明见 [隐私政策](PRIVACY.md)。

## 当前边界

- 扩展翻译网页中的真实文字节点，不识别视频画面、图片或 Canvas 内已经绘制好的文字。
- 网站自身反复重绘的少量辅助标签可能稍后才完成翻译。
- Chrome 扩展商店、`chrome://` 等浏览器保护页面禁止扩展注入，少邻国无法改写这些页面。
- Chrome 未提供对应语言模型且本机翻译服务未运行时，原文会保持可见，不会上传到远端服务。
