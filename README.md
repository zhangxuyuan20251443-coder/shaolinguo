# 少邻国

少邻国是一款把网页外文直接改写在原文字位置的 Chrome 扩展。它不在旁边另开翻译框，也不把译文盖成贴片；网页显示时，标题、正文、按钮和动态加载的评论会直接变成目标语言。

![少邻国封面](store-assets/cover-1400x560.png)

## 主要功能

- 自动识别网页原文语言，也可以手动指定原文语言。
- 可翻译为简体中文、英语、日语、韩语、西班牙语、法语、德语、俄语、阿拉伯语、葡萄牙语、意大利语、土耳其语、越南语和泰语。
- 直接修改网页原有文字节点，不生成悬浮窗、截图或翻译贴片。
- 支持 YouTube 等动态网页，滚动到评论区后继续翻译新加载的内容。
- 自动保留文件名、路径、网址、电子邮箱和代码标识。
- 可维护“不翻译词表”，默认保留 KFC、YouTube、Google、Apple、macOS 等名称。
- 默认优先使用 Chrome 设备端翻译能力；需要时可回退到用户电脑上的少邻国本机语义翻译服务。

## 使用

1. 点击工具栏中的少邻国图标。
2. “网页原文”保持“自动识别”，或手动选择原文语言。
3. 在“翻译成”中选择目标语言。
4. 点击“应用并刷新当前网页”。

扩展会从当前视口开始翻译，并在滚动时处理新出现的内容。文件名、网址和“不翻译词表”中的专有词不会被改写。

## 本地安装

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 选择“加载未打包的扩展程序”，然后选择本仓库目录。

## 数据处理

少邻国不会把网页内容发送到开发者服务器。翻译通过 Chrome 的设备端翻译能力完成；如果用户在本机运行少邻国语义翻译服务，扩展只会连接 `127.0.0.1:11436`。详细说明见 [隐私政策](PRIVACY.md)。

## 当前边界

- 扩展翻译网页中的真实文字节点，不识别视频画面、图片或 Canvas 内已经绘制好的文字。
- 网站自身反复重绘的少量辅助标签可能稍后才完成翻译。
- Chrome 未提供对应语言模型且本机翻译服务未运行时，原文会保持可见，不会上传到远端服务。
